El plan es el mismo para todos

Los pasos del plan oficial no cambian con tu perfil. Lo que cambia es dónde te conviene fijarte más y qué te resultará más fácil. Esta tabla es una orientación, no una prescripción.

Tu perfil Refuerzo, si te falta base Dónde fijarte más Qué te resultará más fácil
ML Engineer APIs, Git y terminal Proyecto 1 y Proyecto 2 DataCamp
Data Scientist Python de software (funciones y clases), APIs y Git Proyecto 1 y AWS Cloud Quest DataCamp
Data Engineer Fundamentos de ML, APIs y clases en Python DataCamp y Proyecto 2 AWS Cloud Quest
DevOps Python, SQL y fundamentos de ML DataCamp y Proyecto 2 AWS Cloud Quest
Backend Developer Python (si no es tu lenguaje) y fundamentos de ML DataCamp y Proyecto 2 Proyecto 1
Fullstack Developer Python, SQL y fundamentos de ML DataCamp y Proyecto 2 Proyecto 1

Rutas por perfil

En cada diagrama puedes ver de un vistazo dónde te conviene fijarte más y qué te resultará más fácil.

ML Engineer → AI Engineer

  • Lo que ya traes: Python, ML y datos.
  • Si te falta base (opcional): APIs, Git y terminal: Introduction to APIs in Python, Introduction to Git e Introduction to Shell. Ver los refuerzos opcionales.
  • Tu foco en el plan: Proyecto 1 y Proyecto 2. Aquí pasas del modelo al sistema: respuestas con citas, herramientas y agentes. El track de DataCamp te resultará más llevadero.

Data Scientist → AI Engineer

  • Lo que ya traes: Análisis, ML y notebooks.
  • Si te falta base (opcional): Si solo trabajas en notebooks: funciones y clases en Python (Introduction to Functions in Python, Python Toolbox, Writing Functions in Python e Introduction to Object-Oriented Programming in Python). Además, APIs y Git (Introduction to APIs in Python e Introduction to Git). Ver los refuerzos opcionales.
  • Tu foco en el plan: Proyecto 1 y AWS Cloud Quest. Software que otros puedan mantener (contratos, pruebas) y despliegue en la nube. El track de DataCamp te resultará más llevadero.

Data Engineer → AI Engineer

  • Lo que ya traes: Pipelines, SQL y calidad del dato.
  • Si te falta base (opcional): Fundamentos de ML (Understanding Machine Learning), APIs (Introduction to APIs in Python) y clases en Python (Introduction to Object-Oriented Programming in Python). Ver los refuerzos opcionales.
  • Tu foco en el plan: El track de DataCamp y el Proyecto 2. Llevar la calidad del dato a la calidad de la respuesta: primero RAG, después herramientas y evaluación. AWS Cloud Quest te resultará más llevadero.

DevOps → AI Engineer con foco operativo

  • Lo que ya traes: Plataforma, contenedores, CI/CD y nube.
  • Si te falta base (opcional): Python (solo lo que te falte), SQL (Introduction to SQL e Intermediate SQL) y fundamentos de ML (Understanding Machine Learning). Ver los refuerzos opcionales.
  • Tu foco en el plan: El track de DataCamp y el Proyecto 2. Prompts, RAG y evaluar si las respuestas son buenas: que un contenedor arranque no demuestra que las respuestas sean correctas. AWS Cloud Quest te resultará más llevadero.

Backend Developer → AI Engineer

  • Lo que ya traes: APIs, servicios y pruebas.
  • Si te falta base (opcional): Python, si no es tu lenguaje (Introduction to Python for Developers e Intermediate Python for Developers), y fundamentos de ML (Understanding Machine Learning). Ver los refuerzos opcionales.
  • Tu foco en el plan: El track de DataCamp y el Proyecto 2. Sistemas que no siempre responden igual: evaluación, RAG y agentes. Un HTTP 200 no significa que la respuesta sea buena. El Proyecto 1 te resultará más llevadero.

Fullstack Developer → AI Engineer

  • Lo que ya traes: Frontend y backend.
  • Si te falta base (opcional): Python, igual que Backend Developer, SQL (Introduction to SQL e Intermediate SQL) y fundamentos de ML (Understanding Machine Learning). Ver los refuerzos opcionales.
  • Tu foco en el plan: El track de DataCamp y el Proyecto 2. El servicio backend, su estado y su observabilidad: la interfaz no sustituye a la API ni a la evaluación. El Proyecto 1 te resultará más llevadero.

Refuerzos opcionales

Si te falta base en algo, estos cursos de DataCamp pueden ayudarte. Son opcionales: elige solo lo que necesites. Para Python mandan los cursos recomendados que se comparten en el chat del programa.

Intermediate Python Más Python para manejar datos y estructurar la lógica.
Introduction to Functions in Python Definir y reutilizar funciones.
Python Toolbox Iteradores, comprensiones y generadores.
Writing Functions in Python Funciones más robustas y mantenibles.
Introduction to Python for Developers Python para quien ya programa en otro lenguaje.
Intermediate Python for Developers Más herramientas de Python para el desarrollo de software.
Introduction to APIs in Python Consumir APIs con peticiones HTTP y datos JSON.
Introduction to Git Control de versiones con Git.
Introduction to Shell Trabajar desde la terminal.
Introduction to Object-Oriented Programming in Python Clases y objetos en Python.
Introduction to SQL Consultas básicas a una base de datos.
Intermediate SQL Consultas más avanzadas: filtrar, agrupar y agregar.
Understanding Data Engineering Conceptos de ingeniería de datos y de pipelines.
Containerization and Virtualization Concepts Qué es un contenedor y en qué se diferencia de una máquina virtual.
