El plan oficial en un vistazo

Seis pasos, en este orden. Termina un paso antes de empezar el siguiente.

  1. roadmap.sh, rol AI Engineer. Glosario y checklist personal de conceptos. Es una primera lectura: no hace falta estudiarlo todo.
  2. DataCamp, track «Associate AI Engineer for Developers». Obligatorio para todos, con cuenta personal.
  3. Proyecto 1. Chatbot básico (texto, imágenes e historial de conversación) con LangChain y FastAPI.
  4. Proyecto 2. Agente con RAG, con LangChain y FastAPI. Langfuse es opcional para las trazas.
  5. AWS Cloud Quest. Empieza por la isla de fundamentos si no conoces AWS; después, las de IA.
  6. Certificación (opcional). AWS (AI Practitioner o Generative AI Developer) o LangChain. ERNI paga el examen.

Los dos proyectos se hacen a mano al menos una vez, sin pedírselo entero a un asistente de código, y se presentan en una sesión de seguimiento. Como referencia, usa la documentación de LangChain y LangGraph y la de FastAPI.

Seguimiento y calendario orientativo

  • Seguimiento: online, cada dos semanas. Cuentas qué has hecho, planteas dudas y bloqueos.
  • Programa opcional: es compatible con tu trabajo. Si lo dejas, avisa.

Qué es un AI Engineer

No entrenas modelos: construyes productos con modelos que ya existen. Alrededor del modelo diseñas lo que falta: buscar en documentos, consultar sistemas con permisos, validar la salida, medir la calidad y desplegar.

Definición oficial y ejemplo

La definición oficial del programa dice: «An AI Engineer builds products on top of Generative AI Foundation Models, rather than training models from scratch. Starts with the user need, selects an API or open model, then designs the application around it.»

Ejemplo: los operadores de soporte pierden tiempo buscando el procedimiento correcto. Un AI Engineer parte de esa necesidad, elige un modelo (por API o abierto) y construye alrededor lo que falta.

Stack típico del rol

No tienes que dominarlo todo; sirve para ubicarte.

  • Lenguajes: Python (también JS/TS y Java).
  • Orquestación de LLM: LangChain, LangGraph, Strands (y alternativas como PydanticAI, CrewAI o Mastra).
  • Observabilidad y pasarela de modelos: LangFuse y LiteLLM (también MLflow y LangSmith).
  • Nube: AWS y Bedrock (o Azure y AI Foundry).
  • Backend y despliegue: FastAPI; Docker en ECS, Fargate, Azure Container Apps o AgentCore; algo de frontend con React o Streamlit.
  • Modelos abiertos y locales: Ollama, vLLM, llama.cpp y Hugging Face.
  • Datos para RAG: ChromaDB, Qdrant y Postgres.

Norma de acceso a modelos

Los modelos se consumen siempre por la pasarela LiteLLM de ERNI, con tu clave individual. No uses otros servicios ni claves personales.

Para Python, los cursos recomendados se comparten en el chat del programa.

Antes de empezar

Requisitos técnicos para trabajar con comodidad:

  • Python y un entorno de desarrollo (IDE) en tu ordenador.
  • Git.
  • Docker, más adelante, cuando llegues a los contenedores.
  • Leer inglés técnico: la documentación y casi todos los cursos están en inglés.
